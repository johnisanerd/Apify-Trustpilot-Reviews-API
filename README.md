# Trustpilot Reviews API examples (retired)

> **I've retired Trustpilot Reviews API, so the examples in this repo no longer work.** The repo is archived and kept for reference.
> For customer review data, use my **[Yelp Reviews API](https://apify.com/johnvc/Yelp-Reviews-API?fpr=9n7kx3)** instead, and start from its example repo, [Apify-Yelp-API](https://github.com/johnisanerd/Apify-Yelp-API).

## Use instead

- **[Yelp Reviews API](https://apify.com/johnvc/Yelp-Reviews-API?fpr=9n7kx3)**: reviews for any Yelp business, with rating, full text, date, reviewer stats, photos and owner replies. Example repo: [Apify-Yelp-API](https://github.com/johnisanerd/Apify-Yelp-API).
- **[Glassdoor Reviews API](https://apify.com/johnvc/glassdoor-reviews-api?fpr=9n7kx3)**: employer reviews with overall and category ratings, pros and cons. Example repo: [Apify-Glassdoor-Reviews-API](https://github.com/johnisanerd/Apify-Glassdoor-Reviews-API).
- **[Apple App Store Reviews API](https://apify.com/johnvc/apple-app-store-reviews-api?fpr=9n7kx3)**: app reviews with ratings, text, dates and versions across 50+ country stores. Example repo: [Apify-Apple-App-Store-Reviews-API](https://github.com/johnisanerd/Apify-Apple-App-Store-Reviews-API).
